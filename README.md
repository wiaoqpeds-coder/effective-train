# YouTube-бот для Telegram

Скачивает видео по ссылке и присылает файл в чат.

## Установка

1. Создай бота через [@BotFather](https://t.me/BotFather), получи токен.
2. Установи Python 3.10+ и [ffmpeg](https://ffmpeg.org/download.html) (нужен для yt-dlp).
3. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Укажи токен через переменную окружения:

   ```bash
   export BOT_TOKEN="твой_токен_от_BotFather"
   ```

   (в Windows: `set BOT_TOKEN=твой_токен`)

## Запуск локально

```bash
python bot.py
```

Бот начнёт опрашивать Telegram (polling) — просто оставь скрипт работать (на сервере/VPS/своём ПК).

## Деплой на Railway

1. Залей папку с проектом в GitHub-репозиторий (файлы `bot.py`, `requirements.txt`, `Procfile`, `nixpacks.toml` должны лежать в корне репозитория).
2. На [railway.app](https://railway.app) нажми **New Project → Deploy from GitHub repo** и выбери свой репозиторий.
3. В настройках проекта (**Variables**) добавь переменную:
   - `BOT_TOKEN` = токен от BotFather
4. Railway сам подхватит `nixpacks.toml` и поставит ffmpeg, а `Procfile` укажет, что нужно запускать процесс типа **worker** (не web) командой `python bot.py`.
5. Важно: в разделе **Settings → Deploy** убедись, что запущен процесс `worker`, а не `web` — у бота нет http-сервера, слушать порт не нужно. Если Railway ругается, что "No open ports found" — это нормально для polling-бота, просто игнорируй (либо явно выставь его как worker-сервис в настройках).
6. После деплоя посмотри логи — там должна появиться строка `Бот запущен`. Дальше просто пиши боту в Telegram.

## Как увеличить лимит с 50 МБ до 2 ГБ

По умолчанию Telegram ограничивает ботов 50 МБ на файл. Чтобы поднять лимит до ~2 ГБ,
нужно развернуть свой **локальный Bot API сервер** — второй, отдельный сервис на Railway,
к которому подключится твой бот.

### Шаг 1. Получи api_id и api_hash

1. Зайди на https://my.telegram.org, войди под своим номером телефона.
2. Раздел **API development tools** → создай приложение → получишь `api_id` и `api_hash`.

### Шаг 2. Задеплой сервер telegram-bot-api как отдельный сервис на Railway

В папке `bot-api-server/` лежит `Dockerfile` для этого.

1. В том же Railway-проекте нажми **New → GitHub Repo** (или **Empty Service**, если удобнее) и укажи путь к папке `bot-api-server` как корень сборки (Root Directory в настройках сервиса).
2. В **Variables** этого сервиса добавь:
   - `TG_API_ID` = твой api_id
   - `TG_API_HASH` = твой api_hash
3. Railway соберёт образ по Dockerfile и запустит сервер. В настройках сервиса включи публичный домен (**Settings → Networking → Generate Domain**) — получишь адрес вида `https://xxxx.up.railway.app`.

### Шаг 3. Подключи бота к этому серверу

В переменных сервиса с ботом (`bot.py`) добавь:
- `LOCAL_BOT_API_URL` = адрес из шага 2, например `https://xxxx.up.railway.app`
- `MAX_FILE_SIZE_MB` = 2000 (или меньше, если хочешь ограничить сам)

Код бота сам подхватит эти переменные и переключится на локальный сервер — больше ничего менять не нужно.

### Важно
- Локальный сервер telegram-bot-api хранит скачанные файлы у себя на диске перед отправкой — на Railway диск эфемерный, но для временной обработки файла этого достаточно.
- Такая связка (два сервиса + больший лимит) требует больше ресурсов — на бесплатном плане Railway может не хватить лимитов, скорее нужен платный тариф.
- Если `LOCAL_BOT_API_URL` не задан — бот как и раньше работает через обычный облачный API с лимитом 50 МБ, ничего не сломается.

### Заметки про Railway
- Бесплатный план Railway имеет лимиты по времени работы/ресурсам — для бота, который должен работать круглосуточно, может понадобиться платный план (Hobby и выше).
- Диск на Railway эфемерный — это нормально, видео скачиваются во временную папку и сразу удаляются после отправки, ничего постоянно не хранится.
- Если видео большие и скачивание долгое, на некоторых планах Railway может убивать процесс по таймауту — стоит проверить на видео разной длины.

## Ограничения

- Telegram Bot API не даёт ботам отправлять файлы больше **50 МБ**. Если видео тяжелее — бот скажет об этом.
  Чтобы снять это ограничение, нужно поднять свой [локальный Bot API сервер](https://github.com/tdlib/telegram-bot-api) — это уже отдельная настройка.
- Скорость скачивания зависит от YouTube и твоего интернета.
- Используй бота только для видео, которые разрешено скачивать (личный контент, лицензии Creative Commons и т.п.) — массовое скачивание чужих видео может нарушать условия использования YouTube.
